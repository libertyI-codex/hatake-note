# 畑ノート Ver.2.0 試作1

家庭菜園の4×4の畑マスと、各マスをいつからいつまで何の作物に使うかを管理する、スマホ優先のローカルWebアプリです。

## 作り直した理由

Ver.1系では、区画、作業記録、写真、育成スケジュール、栽培計画など複数の概念を扱っていました。Ver.2.0では日常操作を簡単にするため、管理対象を次の2つに絞りました。

- 4×4の畑マス
- 使用マス、作物名、開始日、終了予定日を持つ作付け予定

Ver.1系のコードや保存データは使用せず、別アプリとして新規構築しています。

## 基本思想

「現況」と「予定」を別データとして保存しません。すべての作付けに開始日と終了予定日を持たせ、表示日との関係から状態を自動判定します。

- 開始日前：今後の予定
- 開始日から終了予定日まで：栽培中
- 終了予定日後：終了済み

状態のように日付から計算できる値は保存しません。

## 画面構成

画面と下部ナビは次の3つだけです。

1. 畑
2. 年間予定
3. データ

### 畑

- 1〜16番の4×4畑図
- 初期表示日は今日
- 前月、次月、今日、任意の日付への移動
- 選択した正確な日付に栽培中の作物を表示
- 作付けの新規登録、詳細確認、編集、削除

初回起動時はサンプルを登録せず、16マスすべて「空き」と表示します。

### 複数マス選択

新しい作付けでは畑図から1つ以上のマスを選びます。たとえば2・6・10を選んで「じゃがいも」を登録すると、3マスが同じ色、作物名、作付けIDで表示されます。

同じ作付けに属する隣接マスは内側の境界を薄く表示します。離れたマスも同じ色と作付けIDで確認できます。

### 作付け登録・編集・削除

保存項目は次のとおりです。

- 使用するマス
- 作物名
- 開始日
- 終了予定日
- メモ（任意）

編集ではすべての項目を変更できます。終了予定日は開始日以降である必要があります。削除前には確認ダイアログが表示されます。

### 期間重複チェック

次の両方に該当する作付けは保存できません。

- 1つ以上同じマスを使う
- 開始日から終了予定日までの期間が重なる

開始日と終了予定日を含めて重複判定します。編集時は編集中の作付け自身を判定対象から除外します。

### 年間予定

選択した年に該当する作付けを一覧表で表示します。

- 左側：使用マス、作物名、開始日、終了予定日
- 右側：1月〜12月
- 作付け期間に該当する月を色付きで表示
- 前年から継続する作付け、翌年まで続く作付けにも対応
- スマホでは横スクロール可能
- 使用マスと作物名の列を横スクロール時に固定
- 行をタップして詳細を表示

並び順は、使用マスの最小番号、開始日、作物名の順です。

### データ

- JSONバックアップの書き出し
- JSONバックアップの読み込み
- 全作付けデータの削除

復元前にファイルを検証し、読み込み件数を表示します。確認後、現在の作付けデータをバックアップ内容で上書きします。不正なファイルでは現在データを変更しません。

バックアップファイル名は `hatake-note-v2-backup-YYYYMMDD-HHMM.json` です。

## データ構造

```json
{
  "id": "crop-plan-xxxxxxxx",
  "cellIds": [2, 6, 10],
  "cropName": "じゃがいも",
  "startDate": "2026-09-01",
  "endDate": "2026-12-15",
  "memo": "秋じゃが",
  "createdAt": "2026-07-26T00:00:00.000Z",
  "updatedAt": "2026-07-26T00:00:00.000Z"
}
```

`cellIds` は1〜16の重複しない整数配列です。

## 保存仕様

作付けデータはブラウザのlocalStorageへ保存します。

保存キー：

```text
hatakeNoteV2.cropPlans.v1
```

Ver.1系の保存キーやIndexedDBにはアクセスしません。Ver.1系とVer.2.0のデータは完全に別です。

表示日は保存しないため、アプリを開くたびに今日から始まります。

## ファイル構成

```text
hatake-note-v2/
  index.html
  style.css
  data.js
  app.js
  README.md
```

React、外部ライブラリ、CDN、Firebase、Service Workerは使用していません。

## 起動方法

`index.html` をブラウザで開くと使用できます。ブラウザの保存制限を避けて確認する場合は、このフォルダを簡易Webサーバーで配信してください。

例：

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

静的ファイルだけで構成しているため、GitHub Pagesでも公開できます。今回、GitHub Pagesへのアップロードは行っていません。

CSSとJavaScriptの読み込みには次のキャッシュ対策クエリを付けています。

- `style.css?v=20p1`
- `data.js?v=20p1`
- `app.js?v=20p1`

## 注意点

- データは同じ端末、同じブラウザ内だけに保存されます。
- ブラウザデータを削除すると作付けデータも消えます。
- 機種変更や別端末への移行にはJSONバックアップを使用してください。
- PCとスマホの自動同期はありません。
